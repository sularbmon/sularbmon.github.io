# Su Larb Mon — Portfolio

Personal academic and engineering portfolio of Su Larb Mon, Computer Vision & Machine Learning Engineer based in Tokyo, Japan.

## Website

Once GitHub Pages is enabled, visit https://sularbmon.github.io/.

## Structure

- `index.html` — introduction, publications, experience, education and projects
- `styles.css` — responsive academic-style design
- `script.js` — footer year

## Publications

The website links to four research publications via DOI, with arXiv links for the two 2025 HRI papers.

## Deploy with GitHub Pages

Go to **Settings → Pages**, select **Deploy from a branch**, then set **main** and **/(root)**. Save your settings.

## Editing

Update `index.html` for content changes and `styles.css` for styling. Avoid publishing confidential client information without permission.
